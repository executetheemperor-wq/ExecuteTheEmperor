# Name check and prior art

A quick web check (2026-10-11), not a trademark search. Store sites
couldn't be searched directly, so this rests on web-search results.

## The name

**"Execute the Emperor" looks clear.** No game, board game, app, book, mod or
Kickstarter with that title (or *ExecuteTheEmperor*) turned up.

Watch out for **"Kill the Emperor"**: there's already a small Steam game
with that name (a 2023 ghost-story RPG). Don't use it as an alternative
title.
