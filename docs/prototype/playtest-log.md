# Paper prototype — playtest log

One entry per game, newest first. Rule changes go in the entry *and* in
[rules.md](rules.md) or [cards.md](cards.md), so the docs always match the
latest version.

## What we're trying to learn

From [Sprint 1](../sprint-1.md#what-we-want-to-learn):

1. Is drafting co-conspirators interesting — are there real trade-offs?
2. Do the stat interactions (socialite vs military man) create decisions,
   or just bookkeeping?
3. Does Pressure feel like a snowball — good early, scary late?
4. Does "sticky" feel like a fun problem or just a punishment?
5. Is there enough to do each turn without the murder stage?

And one about this version: **how long does a turn really take?** The
target is about 30 seconds ([D3](../decisions.md)).
