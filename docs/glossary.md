# Glossary

Working vocabulary from the notes. Terms marked *(proposed)* are names
picked for this repo, not words from the notes — rename freely.

| Term | Meaning | Where |
|---|---|---|
| **The Emperor** | The target. You need to kill a certain number of them. | All phases |
| **Co-conspirator** | Someone recruited to the cause. | Phase 1 |
| **The cause** | The plot to kill the Emperor. | Phase 1 |
| **The Shadowy Circle** | The forum where the plot is discussed. | Phase 1 |
| **Hire / Charm / Blackmail** | The three ways to bring someone in. | Phase 1 |
| **Values** | Per-person stats; *hate* is the one named so far. | Phase 1 |
| **Grasp** | How tightly you hold someone. Affects whether they need to be part of the plot. | Phase 1 |
| **Execute / Leave alive** | What you do with someone. Alive means they might rat you out. | Phase 1 |
| **Rat you out** | A co-conspirator betrays you — chance you're **ended**. | Phase 1 |
| **Ended** | Your run is over (caught, killed — exact meaning still open). | Phase 1 |
| **Method** | How the Emperor is killed. Each one begets certain bonuses. | Phase 2 |
| **Funding** | Acquired to do it a certain way. | Phase 2 |
| **The Imperial Palace** | The map for planning. Parts can be obscured. | Phase 2 |
| **Obscured** *(map state)* | Parts of the map you can't see — building works, missing plans. | Phase 2 |
| **Getting closer** | Proximity to the Emperor; unlocks more planning actions. | Phase 2 |
| **Suspicion** | Raised by being at the murder. | Phase 3 |
| **Reports** | Word-of-mouth accounts of the murder; how you read them affects which plots grow. | Phase 3 |
| **Crowned** | You win: you've killed enough Emperors. | Meta |
| **Pressure tokens** | Board game: they build; at a value you have to plot. | Board game |
| **Unlocks** | Things unlocked as you go. | Board game |
